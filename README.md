# E-commerce Customer Experience Analysis

Учебный проект по продуктовой аналитике. Цель — определить, какие факторы связаны с оценкой заказа, и оценить возможный эффект от улучшения доставки и рейтингов товаров.

## Данные

Использованы три CSV-файла: заказы, позиции заказов и каталог товаров.

В основном анализе рассмотрено 113 559 завершённых заказов с клиентской оценкой.

Источник: [E-Commerce Sales and Customer Analytics — Kaggle](https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics)

Датасет синтетический.

## Методы

- Подготовка данных и исследовательский анализ (EDA).
- Сравнение оценок между группами.
- Корреляционный анализ.
- Многофакторная линейная регрессия.
- Расчёт сценариев изменения доставки и рейтингов товаров.
- Анализ связи оценок с покупательской активностью.

## Основные результаты

- Средняя оценка заказа — около 3,68 из 5.
- Опоздавшие заказы оцениваются в среднем на 0,50 балла ниже заказов, доставленных вовремя.
- Увеличение среднего рейтинга товаров в заказе на 1 балл связано с повышением оценки заказа примерно на 0,30 балла.
- Сценарий сокращения доли опозданий с 15% до 10% и повышения рейтингов товаров ниже 3,5 до этого порога соответствует расчётному приросту средней оценки примерно на 0,09 балла.
- Выраженной связи оценки заказа с повторными покупками не обнаружено.

Все результаты основаны на наблюдательных данных. Расчётные сценарии не гарантируют аналогичный эффект на практике.
